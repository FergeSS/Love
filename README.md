# Тебе, с любовью ♡

Романтичный адаптивный сайт: объёмное анимированное сердце, 12 комплиментов, письмо и нежная мелодия. Обычные HTML/CSS/JavaScript, сборка и установка зависимостей не нужны.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него все файлы, включая папку `.github/workflows`.
2. Используйте основную ветку `main`.
3. В репозитории откройте **Settings → Pages → Source → GitHub Actions**.
4. Откройте **Actions → Deploy to GitHub Pages → Run workflow** (или отправьте новый коммит в `main`).
5. После успешного выполнения адрес появится в **Settings → Pages** и в окружении **github-pages**.

Сайт доступен по адресу `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

## Как сделать подарок личным

- `index.html`: заголовок, письмо в `<dialog id="letter">`, подпись и тексты.
- `script.js`: массив `compliments` с комплиментами.
- `style.css`: цвета в `:root`.

Для локального просмотра запустите `python3 -m http.server 8080` в папке сайта и откройте `http://localhost:8080`.

Шрифты загружаются из Google Fonts; без сети используются системные. Сердце и музыка работают без внешних библиотек. Музыка включается только по нажатию. Настройка уменьшения движения учитывается.
